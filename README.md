# عبودي AI

تطبيق ويب عربي متكامل للمحادثة مع الذكاء الاصطناعي عبر **Gemini API**، يعمل كخدمة واحدة (واجهة React + خادم Node.js/Express) جاهزة للنشر على **Render**، بحيث يُدخل كل مستخدم مفتاح Gemini API الخاص به داخل التطبيق مع دعم إدارة عدة مفاتيح والتبديل الفوري بينها.

## أبرز الميزات
- **إدارة عدة مفاتيح API من داخل التطبيق (BYOK)**:
  - شاشة ترحيب أولى لإدخال المفتاح مع زر **لصق من الحافظة**، قص تلقائي للمسافات والأسطر، والتحقق الفوري من صلاحية المفتاح عبر الخادم قبل الحفظ.
  - حفظ المفاتيح في المتصفح فقط (`localStorage`) بشكل منفصل تماماً عن المحادثات (ولا تُدرج المفاتيح عند تصدير المحادثات).
  - قسم **الإعدادات ← مفاتيح API** لعرض المفاتيح بآخر 4 رموز فقط (`••••aLRw`)، التفعيل الفوري، إعادة التسمية، الاختبار، الحذف، إضافة مفتاح جديد، وتصدير المحادثات أو مسح كل البيانات.
  - **تبديل سريع** بين المفاتيح من الشريط العلوي بجانب اختيار النموذج.
  - اقتراح التبديل بضغطة واحدة إلى مفتاح محفوظ آخر عند تجاوز الحد (`429`) دون تبديل تلقائي.
- **اختيار النموذج ومستوى التفكير**: قائمة أنيقة (قائمة منسدلة على الكمبيوتر ونافذة سفلية Bottom Sheet على الجوال) لاختيار النموذج (Flash / Flash-Lite / Pro) وضبط مستوى التفكير (`بدون` / `تلقائي` / `منخفض` / `متوسط` / `عالٍ`) مع دعم `thinkingLevel` و`thinkingBudget` تلقائياً حسب كل نموذج.
- **عرض ملخص التفكير**: قسم قابل للطي بعنوان **"عرض التفكير"** فوق الرد (مغلق افتراضياً) يعرض ملخص تفكير النموذج عند توفره، مع عرض اسم النموذج المستخدم أسفل كل رد.
- **بث فوري (Streaming SSE)** وإيقاف التوليد وإعادة التوليد والنسخ.
- **دعم الصور المتعددة**: رفع من المعرض أو الكاميرا على iOS وAndroid، سحب وإفلات، ولصق من الحافظة، مع **ضغط تلقائي للصور في المتصفح** قبل الإرسال.
- **عرض Markdown والأكواد**: تلوين صياغة Syntax Highlighting مع زر نسخ لكل كود.
- **تطبيق PWA متكامل**: قابل للتثبيت على الشاشة الرئيسية في Android وiOS وDesktop ليعمل كتطبيق مستقل.
- **خصوصية وأمان على الخادم**: يُرسل المفتاح في ترويسة `x-api-key` مع كل طلب فقط، ولا يُخزّن أبداً على الخادم أو في ملفات أو سجلات، مع حماية Rate Limiting وإعداد CORS ومسار `/health`.

## 1. كيف تحصل على مفتاح Gemini API من Google AI Studio؟
1. افتح موقع [Google AI Studio](https://aistudio.google.com/apikey) وسجّل الدخول بحساب Google.
2. اضغط على **Create API key** (إنشاء مفتاح API).
3. اختر مشروعاً (أو أنشئ مشروعاً جديداً) ثم انسخ المفتاح.
4. افتح تطبيق **عبودي AI** والصق المفتاح في شاشة الترحيب (أو من الإعدادات لاحقاً).

> **ملاحظة أمان مهمة:**
> - يُحفظ مفتاحك على متصفحك وجهازك فقط. لا تستخدم التطبيق بمفتاحك على جهاز عام أو مشترك.
> - إن ظننت أن مفتاحك انكشف فاحذفه فوراً من [Google AI Studio](https://aistudio.google.com/apikey) وأنشئ مفتاحاً جديداً.

## 2. نشر المشروع على Render (لا يحتاج GEMINI_API_KEY!)
لم يعد النشر على Render يتطلب إضافة متغير `GEMINI_API_KEY`، لأن كل مستخدم يُدخل مفتاحه الخاص داخل التطبيق في متصفحه.

### الطريقة الأولى: النشر السريع عبر `render.yaml` (Blueprint — الأسهل)
1. ارفع أحدث التعديلات إلى مستودعك على GitHub (`ABOODY97/abood_ai`).
2. سجّل الدخول إلى [Render Dashboard](https://dashboard.render.com).
3. اضغط **New +** ثم اختر **Blueprint**.
4. اربط حسابك على GitHub واختر مستودع **abood_ai**.
5. اترك `ALLOWED_ORIGINS` فارغاً (الطلبات من نفس الرابط مسموحة تلقائياً) — **ولا تحتاج لإضافة `GEMINI_API_KEY`**.
6. اضغط **Apply / Deploy** وانتظر دقيقتين حتى يكتمل البناء، ثم افتح الرابط العام الذي يمنحك إياه Render (`https://aboodi-ai.onrender.com`).

### الطريقة الثانية: إنشاء Web Service يدوياً
1. في [Render Dashboard](https://dashboard.render.com)، اضغط **New +** ثم **Web Service**.
2. اختر مستودعك **abood_ai** من GitHub واضبط الإعدادات التالية:
   - **Runtime**: `Node`
   - **Build Command**: `npm ci --include=dev && npm run build`
   - **Start Command**: `npx tsx server.ts`
   - **Health Check Path**: `/health`
   - **Instance Type**: `Free`
3. من تبويب **Environment** أضف المتغيرات:
   - `NODE_ENV` = `production`
   - `NODE_VERSION` = `22.14.0`
   - `RATE_LIMIT_MAX` = `30`
   - `RATE_LIMIT_WINDOW_MS` = `60000`
   - *(اختياري فقط)* يمكنك إضافة `GEMINI_API_KEY` كخيار احتياطي على الخادم إن أردت، لكنه غير مطلوب إطلاقاً.
4. اضغط **Create Web Service**.

> **تنبيه مهم حول الخطة المجانية في Render:**
> في الخطة المجانية (`Free`)، تدخل الخدمة في وضع السكون (Sleep) تلقائياً بعد حوالي 15 دقيقة من عدم الاستخدام. عند فتح الرابط بعد فترة خمول، قد يتأخر أول طلب لمدة **30 إلى 50 ثانية** ريثما يستيقظ الخادم، ثم يعود التطبيق سريعاً بشكل طبيعي.

## 3. كيف تضيف نموذجاً جديداً أو تعدّل النماذج؟
جميع النماذج معرّفة في ملف واحد فقط: **`src/config/models.config.ts`**.

لإضافة نموذج جديد (مثلاً نموذج Pro أو Flash جديد)، افتح `src/config/models.config.ts` وأضف عنصراً داخل مصفوفة `MODELS`:

```ts
{
  id: 'gemini-2.5-flash-lite',
  name: 'Gemini 2.5 Flash-Lite',
  family: 'flash-lite',
  shortTag: 'اقتصادي وسريع',
  description: 'مناسب للاستجابات السريعة وتقليل استهلاك الرموز.',
  supportsMultimodal: true,
  thinking: {
    mode: 'budget', // استخدم 'level' لنماذج Gemini 3/4 أو 'budget' لنماذج Gemini 2.5 أو 'none' إن لم يدعم التفكير
    canDisable: true,
    defaultLevel: 'none',
    supportedLevels: ['none', 'auto', 'low', 'medium', 'high'],
    budgetMap: {
      none: 0,
      auto: -1,
      low: 1024,
      medium: 4096,
      high: 16384,
    },
  },
}
```
سيظهر النموذج الجديد تلقائياً في القائمة المنسدلة وعلى الجوال، وسيستخدم الخادم معامل التفكير الصحيح له دون تعديل أي ملف آخر.

## 4. التشغيل المحلي للتطوير
```bash
# 1. تثبيت الاعتماديات
npm install

# 2. تشغيل التطبيق مباشرة (الواجهة + الخادم على المنفذ 3000)
# لا حاجة لإعداد .env؛ يمكنك إدخال مفتاح Gemini API مباشرة من شاشة الترحيب داخل التطبيق
npm run dev
```
ثم افتح المتصفح على `http://localhost:3000`.
